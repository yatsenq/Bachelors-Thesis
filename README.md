# Bachelor's Thesis

Комбінована система виявлення дезінформації в україномовному
новинному контенті на основі трансформерних моделей
та фактологічної верифікації.

## Структура

- `data/` — початкові й оброблені дані, докази та розбиття вибірок.
- `notebooks/` — дослідницькі ноутбуки.
- `src/data/` — збір, очищення й підготовка даних.
- `src/classification/` — навчання та використання класифікатора.
- `src/retrieval/` — пошук доказів.
- `src/verification/` — перевірка тверджень за доказами.
- `src/fusion/` — поєднання результатів компонентів.
- `src/web/` — вебінтерфейс.
- `experiments/configs/` — налаштування експериментів.
- `experiments/results/` — метрики й результати.
- `experiments/plots/` — графіки.
- `models/` — ваги моделей, які не зберігаються в Git.
- `docs/thesis/` — текст дипломної роботи.
- `docs/references/` — список джерел і нотатки.
- `docs/diagrams/` — схеми.
- `docs/screenshots/` — знімки екрана.
- `tests/` — перевірки програмних компонентів.
