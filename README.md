# Bachelor's Thesis

Комбінована система виявлення дезінформації в україномовному новинному
контенті на основі трансформерних моделей та фактологічної верифікації.

## Структура

- `src/data/` — парсери джерел і підготовка датасету тверджень.
- `notebooks/` — класифікація (TF-IDF + логістична регресія) і пошук доказів.
- `data/raw/` — сирі матеріали джерел (не зберігаються в Git).
- `data/processed/` — підготовлені твердження (не зберігаються в Git).
- `data/splits/` — зафіксоване розбиття на навчальну й тестову вибірки.
- `data/evidence/` — збережений пошуковий індекс.
- `models/` — збережені моделі (не зберігаються в Git).
- `experiments/` — результати та графіки.
- `docs/` — текст роботи й діаграми.
